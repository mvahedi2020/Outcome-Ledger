## Meaningful recovery exercises

With an invalid saved record, the page announces preservation and rejects attempts to save a review over it. Export current work, preview reset, and confirm only when the raw record remains unchanged. A competing tab that changes saved bytes after preview causes confirmation to reject; Load saved state and re-review. If storage cannot be read, reviews remain memory-only and reset is unavailable; refresh or close may lose unsaved work. Restore access and load saved state before proceeding.

These are reproducible software scenarios, not evidence of a completed human usability study.
